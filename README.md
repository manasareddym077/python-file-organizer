 organizes files into folders based on their file types.

## Features
- Organizes images into the Images folder
- Organizes documents into the Documents folder
- Organizes audio files into the Audio folder
- Organizes videos into the Videos folder

## Technologies
- Python
- os module
- shutil module

## How to Run

Run the following command:

python file_organizer.py

The program automatically moves files into the appropriate folders.

## Sample Output

Moved: photo.jpg -> Images
Moved: resume.pdf -> Documents
Moved: notes.txt -> Documents
Moved: song.mp3 -> Audio
Moved: video.mp4 -> Videos

File organization completed!
